# Rano

Rano is a terminal-based text editor written in Rust, inspired by **Cano** by Cobb Coding.

## Features

- Open a file or start with an empty buffer
- Navigate with arrow keys
- Quit with `q`
- Simple terminal interface
- Lightweight and fast

## Installation

Make sure you have Rust installed. Then clone the repository:

```bash
git clone https://github.com/roypery2010/rano.git
cd rano
cargo build
cargo run
